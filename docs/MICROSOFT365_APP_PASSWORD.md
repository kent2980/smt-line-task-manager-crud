# Microsoft 365 アプリパスワード生成方法

Microsoft 365からメールを送信する際、2要素認証が有効なアカウントでは、通常のパスワードではなく**アプリパスワード**を使用する必要があります。

## アプリパスワード生成手順

### 方法1: Microsoft 365セキュリティ設定から生成（推奨）

1. **Microsoft 365にサインイン**
   - <https://www.office.com> にアクセス
   - アカウントにサインイン

2. **セキュリティ設定にアクセス**
   - 右上のアカウントアイコンをクリック
   - 「マイアカウント」を選択
   - 「セキュリティ」タブをクリック
   - または直接 <https://account.microsoft.com/security> にアクセス

3. **2要素認証の確認**
   - 「追加のセキュリティ検証」または「2段階認証」セクションを確認
   - 2要素認証が有効になっていることを確認
   - 有効になっていない場合は、まず2要素認証を有効にする必要があります

4. **アプリパスワードを生成**
   - 「アプリパスワード」セクションを探す
   - 見つからない場合は、以下のいずれかを試してください：
     - 「セキュリティの詳細」→「アプリパスワード」
     - 「追加のセキュリティ検証」→「アプリパスワード」
   - 「新しいアプリパスワードを作成」または「アプリパスワードを作成」をクリック
   - アプリ名（例：「PowerShellメール送信」）を入力
   - 「生成」または「作成」をクリック

5. **パスワードをコピー**
   - 生成された16文字のパスワードをコピー
   - **重要**: このパスワードは一度だけ表示されます
   - すぐに`.env`ファイルに保存してください

**注意**: 組織のポリシーによっては、アプリパスワードの生成が制限されている場合があります。
その場合は、管理者に問い合わせてください。

### 方法2: Azure Active Directoryから生成（管理者向け）

1. **Azure Portalにアクセス**
   - <https://portal.azure.com> にアクセス
   - Azure Active Directoryにサインイン

2. **ユーザー設定**
   - 「ユーザー」→ 対象ユーザーを選択
   - 「認証方法」を選択
   - 「アプリパスワード」セクションから生成

## .envファイルへの設定

生成したアプリパスワードを`.env`ファイルに設定します：

```env
EMAIL_PASSWORD=生成された16文字のアプリパスワード
```

## 注意事項

1. **アプリパスワードは一度だけ表示**
   - 生成後、すぐにコピーして保存してください
   - 忘れた場合は、新しいアプリパスワードを生成する必要があります

2. **2要素認証が必須**
   - アプリパスワードを使用するには、アカウントで2要素認証が有効である必要があります
   - 2要素認証が無効な場合は、通常のパスワードを使用できます

3. **セキュリティ**
   - アプリパスワードは`.env`ファイルに保存してください
   - `.env`ファイルは`.gitignore`に含まれているため、Gitにコミットされません
   - パスワードをコードに直接記述しないでください

4. **アプリパスワードの管理**
   - 不要になったアプリパスワードは削除できます
   - セキュリティ設定から「アプリパスワード」セクションで管理できます

## トラブルシューティング

### アプリパスワードが見つからない場合

- 2要素認証が有効になっているか確認してください
- 組織のポリシーでアプリパスワードが無効になっている可能性があります
- 管理者に問い合わせてください

### 認証エラーが発生する場合

- アプリパスワードが正しくコピーされているか確認してください
- `.env`ファイルの`EMAIL_PASSWORD`に正しい値が設定されているか確認してください
- パスワードに余分なスペースや改行が含まれていないか確認してください

### 基本認証が無効になっている場合

一部のMicrosoft 365アカウントでは、セキュリティ強化のため基本認証（ユーザー名/パスワード認証）が無効になっている場合があります。
この場合、OAuth2認証を使用する必要があります。
